# 👟 Lugz Footwear Showcase

A clean, modern, and interactive product display page for **Lugz Footwear**, built using **HTML5** and custom **CSS3 Flexbox**. The project features dynamic product cards, vibrant typography accents, interactive hover effects, and a custom dark street-style geometric background.

---

## 🌐 Live Demo

Check out the live page here:
👉 **[View Lugz Footwear Live Page](https://your-username.github.io/lugz-footwear/)**

---

## 🌟 Key Features

* **Responsive Flexbox Grid:** Cards automatically align side-by-side on desktop screens and wrap gracefully on smaller devices.
* **Custom Shoe Wallpaper Background:** Designed with multi-layered CSS radial and linear gradients for a sleek dark-mode aesthetic with golden ambient glow.
* **Interactive Card Animations:** Dynamic hover effects (`transform` and `box-shadow`) lift cards when hovered over.
* **Color-Coded Cards:** Individual styling for different Lugz shoe colors (Brown, Black, White, Red, Grey, Blue, Green).
* **Clean & Semantic HTML Structure:** Header, layout wrapper, and product cards organized cleanly for easy maintenance.
